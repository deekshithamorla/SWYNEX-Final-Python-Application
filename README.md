# SWYNEX-Final-Python-Application
A complete Python application developed as part of the SWYNEX internship Task 4. This project focuses on clean code structure, input validation, error handling, and proper documentation. It includes application code, project organization, and setup instructions in the README file.
SWYNEX Final Python Application

Project Overview

This project is developed as part of the SWYNEX internship Task 4. It is a simple Python application that calculates the sum of numbers entered by the user.

Features

- User input handling
- Input validation
- Error handling
- Clean and simple code structure
- Easy-to-understand output

Technologies Used

- Python 3
- GitHub

Project Structure

- main.py – Main Python application
- requirements.txt – Project dependencies
- README.md – Project documentation

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py

5. Enter numbers separated by spaces.
